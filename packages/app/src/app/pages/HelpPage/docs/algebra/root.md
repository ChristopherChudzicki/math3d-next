---
name: nth root
latex: \operatorname{root}(x, n)
keyboard: root(x, n)
summary: The real \(n\)th root of \(x\)
tags:
  - algebra
---

For a negative \(x\) and an odd \(n\), this is the real root: \(\operatorname{root}(-8, 3) = -2\). \(n\) can be a variable.

For a negative \(x\) and an even \(n\) there is no real root, and the result is an error.
