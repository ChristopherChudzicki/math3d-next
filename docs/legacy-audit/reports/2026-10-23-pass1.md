# Legacy audit, pass 1

Method: [pass-1 spec](../2026-10-23-pass1-spec.md). Snapshot: prod, pulled 2026-10-22, 101,142 legacy scenes. math3d-next branch `legacy-audit/translator-fixes`; math3d-react `master` (`2fce4dd`) plus the audit commit (`200b0d9`). The deployed math3d-react commit is not confirmed (the repo has no release tags). Aggregates only.

## Short version

- **All but 2 of 101,142 scenes are pass-1-clean; 99.49% (99.83% weighted) are clean and fully checked.** The gap is `needs_eval`: cameras over a zero or symbolic axis scale and vector fields with symbolic samples, which need pass 2.
- **No scene crashes.**
- **Three owner policies change what math3d-react showed** (below). One, blank calculated visibility, hides items in 12 of the 100 most-viewed scenes; those need a check by hand before the cutover ([README](../README.md#manual-checks)).
- **The audit checks itself:** five bugs injected into the translator are each flagged (mutation test), and the array-index shift is checked against math3d-next's parser on every legacy expression.

## Owner policies

Each one deliberately differs from what math3d-react rendered:

- **`zOrder`:** math3d-next's automatic order (tree order, surfaces last; #1010) instead of math3d-react's `(1-opacity)·100`. Matters only where a translucent graphic overlaps another: 24% of scenes (29% weighted) have two or more translucent graphics.
- **Blank calculated visibility keeps the author's `visible`:** 12,285 items in 5,059 scenes (9% weighted), mostly the built-in `yz`/`zx` grids. math3d-react showed them on load, because toggling any switch variable turns calculated visibility on for every graphic; math3d-next hides them, as the author saw while editing. A blank expression, including LaTeX spacing, becomes empty.
- **Slider speeds 1.5× and 3× become 2× and 4×**, the nearest math3d-next options: 1,532 sliders in 1,363 scenes animate a third faster.

Also settled, matching math3d-react:

- slider `fps` 60 (its effective rate);
- polar r-range parameter `θ`;
- a blank `zIndex` becomes `"0"`;
- computed cameras don't update on drag (math3d-react locked them);
- array indices shift from 1-based to 0-based, so `a[1]` keeps meaning the first entry (880 scenes).

## Translator bugs fixed

- Camera divided by the default axis scales (38,450 scenes), and orthographic cameras kept math3d-react's 50× dolly.
- Cameras over a symbolic axis scale used the default scale (320 scenes); their position is now an expression over the scale. A blank scale is 1, as math3d-next evaluates it (29 scenes).
- Default items and folders merged whole, not per property: grid `axes` and `visible` (11,833 scenes), folder descriptions (26,647, editor only).
- Grid `width`/`snap` hard-coded (3,071 and 964 scenes).
- Slider speeds without an exact math3d-next option, 1/16× among them, became `1` (1,309 scenes).
- Vector-field `samples` regex: kept `\right` (783 scenes), split inside nested commas (76), and replaced a symbolic value with the default (27; now indexed per direction).
- Surface samples/grid counts not swapped when a range depends on the other parameter (26 scenes).
- Unknown legacy properties crashed the translator (1 scene).

## Remaining

- `VARIABLE` names saved with a trailing `=` (2 scenes).
- `needs_eval`, for pass 2: 489 cameras over a zero or symbolic axis scale (or a non-numeric position), and 43 vector fields with symbolic samples.
- Brackets after a LaTeX command are not shifted: `\sqrt[3]{x}` is a root degree, and the few `\log[t]`, `\sin[…]`, `\pi[…]` are broken in both apps.

## Rendering differences outside pass 1

- A vector field with 1 sample in a direction renders at the range minimum; math3d-react centred it. Filed: `tk-vector-fields-a-direction-with-1-sample-renders--1f7fc4`.
- A translucent surface drawn before an opaque one hides the opaque one's far side. Filed: `tk-automatic-draw-order-translucent-surfaces-can-hi-7210e4`; pass 3 oversamples these scenes.
- A calculated visibility that fails to evaluate shows the item in math3d-react and hides it in math3d-next. Pass 2 counts these.
